# Автоматизация тестирования Stellar Burgers

# Проект содержит UI-тесты веб-приложения Stellar Burgers, написанные на Python с использованием Selenium и pytest.

## Что проверяют тесты:

### Регистрация

# успешная регистрация пользователя;
# ошибка при вводе некорректного пароля.

### Вход

# через кнопку «Войти в аккаунт» на главной странице;
# через «Личный кабинет»;
# через ссылку в форме регистрации;
# через ссылку в форме восстановления пароля.

### Личный кабинет

# переход в личный кабинет;
# переход из личного кабинета в конструктор;
# переход в конструктор по логотипу;
# выход из аккаунта.

### Конструктор

# Проверяется переход между разделами:

# Булки;
# Соусы;
# Начинки.

## Установка зависимостей

# Установить зависимости: pip install -r requirements.txt

## Запуск тестов

# Для запуска всех тестов: pytest


# Для запуска тестов отдельного файла:

# pytest tests/test_registration.py
# pytest tests/test_login.py
# pytest tests/test_personal_account.py
# pytest tests/test_constructor.py
